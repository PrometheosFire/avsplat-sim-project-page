# AVSplat-Sim Project Page

Static GitHub Pages site for the thesis project.

Public URL: https://prometheosfire.github.io/avsplat-sim-project-page/

## Updating the video section

Place optimized MP4 clips in `assets/videos/`, then replace the three "Coming soon" entries in `index.html` with video elements and captions. Keep each file below GitHub's 100 MB per-file limit. Use relative paths such as `assets/videos/closed-loop.mp4` so the clips load from the project-site URL.

The site is served from the root of the `main` branch. Push updates to that branch to publish them without changing the URL.
